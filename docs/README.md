# Documentation

This documentation follows the [Diátaxis framework](https://diataxis.fr/), which categorizes content into four distinct modes:

- **Tutorials**: Lessons that take the reader by the hand through a series of steps to complete a project.
- **How-to guides**: Practical step-by-step guides for the user who has a problem to solve.
- **Reference**: Technical descriptions of the machinery and how to operate it.
- **Explanation**: Clarification and discussion of topics.
